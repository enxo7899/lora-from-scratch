lora-from-scratch: adapting a small language model to new text by training a small fraction of its weights

EmSoft, lab notebook. Builds on transformer-from-scratch.

Abstract. A small pretrained transformer is adapted to source code by training two thin matrices per layer instead of its weights. The backward pass, the adapters and the merge are written by hand, and every figure below runs the same adapter files in plain JavaScript.

1Switching an adapter on

The base model has only read Python documentation. An adapter is a small file, a few hundred kilobytes at most, that changes how it writes. Figure 1 generates from one prompt and seed, so any difference between two runs is the adapter and nothing else. Each token is shaded by how unlikely the model found it.
